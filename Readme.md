# Long Way Home Landing Page

A static marketing site for the book *Long Way Home*, charting the journey from digital nomad to living with rooted purpose.

## Getting started

Open `index.html` in your browser to explore the landing page locally. The page references fonts from Google Fonts and background imagery hosted on Unsplash.

## Project structure

- `index.html` – landing page markup
- `styles.css` – responsive layout and visual styling
- `docs/landing-page-prd.md` – original product requirements document for reference

## Deployment

Serve the site with any static hosting solution (GitHub Pages, Netlify, Vercel, etc.). Ensure `index.html` is at the root so the landing page is available at `/` instead of returning a 404 error.
